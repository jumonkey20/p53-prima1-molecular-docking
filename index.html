Virtual Screening Protocol

Methodology
  1. Load Molecules: Prepare and import PDBQT ligand and macromolecule target structural files.
  2. Search Space: Define bounding box grids around receptor active binding coordinates.
  3. Execute Vina: Run docking calculations to compute relative binding affinities (kcal/mol).
